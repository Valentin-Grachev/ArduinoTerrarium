# ArduinoTerrarium

Контроллер террариума на ESP32. Плата читает температуру и влажность с датчика AHT20, раз в десять минут пишет измерения в файл, сохраняя время в UTC+0, значения температуры и влажности. Затем по этим данным собирается статистика и строится график за последние сутки. График и текущие показатели отображаются в веб-панели, доступ к которой осуществляется при подключении платы к сети Wi-Fi по адресу локального сервера, который поднимается на плате.

## Сборка устройства

Подключите датчик AHT20 к плате по следующей схеме:

- ESP32-PIN21 — AHT20-SDA
- ESP32-PIN22 — AHT20-SCL
- ESP32-GND — AHT20-GND
- ESP32-3V3 — AHT20-VIN



## Подключение

1. Нажмите кнопку BOOT на плате, чтобы запустить на ней Bluetooth (встроенный светодиод начнет мигать).
2. С помощью мобильной программы [Serial Bluetooth Terminal](https://www.rustore.ru/catalog/app/de.kai_morich.serial_bluetooth_terminal) подключитесь к устройству "ESP32".
3. В Bluetooth Terminal пропишите команду: `wifi connect <ssid> <password>`, ssid - название вашей Wi-FI-сети, password - пароль. (В случае успешного подключения плата запоминает название сети и пароль и при следующем включении будет автоматически подключаться к этой сети).
4. Откройте Веб-Панель по локальному адресу [http://192.168.1.50](http://192.168.1.50).

## Как это работает

- Настройка подключения к Wi-Fi осуществляется через класс `BluetoothCommandListener`, ответственный за прием команд через Bluetooth.
- Само подключение к Wi-Fi обрабатывается классом `WifiConnection`.
- Стриминг данных в сеть осуществляется через локальный сервер, который поднимается на плате и обрабатывается классом `ServerHandler`.
- Сервер обрабатывает web-запросы от клиента, высылая ему json-ответы на основе данных, полученных от `MeasureStorage` (файл с сохраненными измерениями с метками времени) и `TemperatureHumiditySensor` (датчик температуры и влажности).
- Метки времени синхронизируются через класс `ClockModule`.

## Классы



### TemperatureHumiditySensor

Читает AHT через библиотеку Adafruit AHTX0. Конструктор принимает пины SDA и SCL, `enable()` запускает датчик и делает первый замер. `update()` повторяет чтение каждые 500 мс. Пока датчик отвечает, `isAvailable()` возвращает истину, а `getTemperature()` и `getHumidity()` — последние значения в градусах Цельсия и процентах относительной влажности.

### ClockModule

Синхронизирует системные часы по NTP с серверами `pool.ntp.org` и `time.google.com`. Смещение пояса нулевое: время хранится в UTC. `sync()` запускает запрос, `update()` замечает завершение синхронизации и вызывает `onSuccessSynced`. Пока статус SNTP не стал успешным, `isSynced()` ложен и история не пишется.

### MeasureStorage

Хранит измерения в `/measures.csv` на LittleFS. Первая строка файла — заголовок `utcTimestamp,temperature,humidity`, дальше по одной записи на строку.

`setAutosave()` связывает хранилище с часами и датчиком и задаёт интервал. В прошивке он равен 10 минутам. `update()` пишет строку, только если датчик доступен и часы синхронизированы.

В файле не больше 2000 записей. При переполнении перед новой строкой удаляются первые 500 строк данных, заголовок остаётся. `clear()` оставляет в файле только заголовок. `getData()` читает файл целиком. `tryGetAverageTemperature()` и `tryGetAverageHumidity()` считают среднее по записям, чей UTC-timestamp попал в заданный интервал. Результат каждой записи приходит в `onSaveHandled`.

### WifiConnection

Подключает ESP32 к точке доступа в режиме станции. Пока идёт попытка, состояние — «подключение»; успех или обрыв обрабатываются в `update()`. На попытку отведено 5 секунд. Если связь уже была и пропала, ещё 5 секунд плата ждёт возврата, затем считает себя отключённой.

Удачное подключение сохраняет SSID и пароль в NVS (`Preferences`, пространство имён `wifi`). `reconnect()` при старте читает эти значения и подключается снова. `connect()` принимается только из состояния «отключено». Исход попытки приходит в `onConnectHandled`, обрыв уже установленной связи — в `onDisconnected`.

### BluetoothCommandListener

Слушает Bluetooth Classic. `enable()` поднимает порт с именем устройства, `update()` собирает символы до перевода строки и отдаёт команду в `onCommandReceived`. В прошивке порт включается нажатием кнопки.

### Button

Следит за кнопкой с подтяжкой к питанию. `update()` отсекает дребезг короче 50 мс и считает кликом отпускание после устойчивого нажатия. На клик вызывается `onClick`: в прошивке это включение Bluetooth и мигание светодиода.

### Led

Управляет одним выводом. `on()` и `off()` держат уровень постоянно. `blink()` включает режим мигания, а `update()` переключает вывод каждые 250 мс, пока этот режим не сменят явным включением или выключением.

### ServerHandler

HTTP-сервер на порту 80. `start()` монтирует LittleFS и начинает принимать клиентов, `update()` вызывает `handleClient()`.


| Метод и путь       | Ответ                                        |
| ------------------ | -------------------------------------------- |
| `GET /`            | `data/index.html` из LittleFS                |
| `GET /api/climate` | JSON: `available`, `temperature`, `humidity` |
| `GET /api/history` | JSON: флаг `synced` и 24 почасовых средних   |


`/api/climate` берёт последние показания датчика. `/api/history` делит последние 24 часа UTC на часовые интервалы и для каждого считает среднее по CSV. Если часов ещё нет, в ответе `synced: false` и пустой список `hours`. У обоих JSON-ответов стоит `Cache-Control: no-store`.

## Команды Bluetooth

Команда — одна строка, завершённая `\n`. Имя SSID пишется одним словом, без пробелов; пароль — всё, что стоит после него.


| Команда                          | Что делает                                                                       |
| -------------------------------- | -------------------------------------------------------------------------------- |
| `wifi connect <ssid> <password>` | Подключает Wi-Fi. При успехе пара сохраняется и подхватится при следующем старте |
| `wifi disconnect`                | Разрывает Wi-Fi                                                                  |
| `clock sync`                     | Заново запрашивает время по NTP                                                  |
| `storage read`                   | Печатает содержимое CSV в Serial (115200)                                        |
| `storage clear`                  | Очищает историю, оставляя заголовок CSV                                          |




## Веб-панель

Страница `data/index.html` — одна, с двумя вкладками.

- **Текущее** показывает влажность и температуру и признак доступности датчика. Запрос к `/api/climate` уходит сразу и далее каждую секунду.
- **История** рисует два графика: средняя влажность и средняя температура. Запрос к `/api/history` уходит сразу и далее раз в минуту. Пока часы не синхронизированы, вместо графиков показывается сообщение об этом.



## Сборка

Нужны [PlatformIO](https://docs.platformio.org/) и плата на порту, который видит Core.

Прошивка:

```bash
pio run -t upload
```

Образ LittleFS собирается из папки `data` (в проекте это страница панели) и заливается отдельно. Тип файловой системы задан в `platformio.ini`: `board_build.filesystem = littlefs`.

```bash
pio run -t uploadfs
```
